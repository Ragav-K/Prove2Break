# Prove2Break

**Study. Prove. Break. Repeat.**

Prove2Break is an Android study-focus app: upload your own study material, let the app extract topics from it, restrict distracting apps while you focus, and earn your breaks — either on a recommended schedule, or early by passing a rapid-fire AI quiz grounded in your own notes.

This repository is currently in **Phase 0 (documentation & project foundation)** — no application code exists yet.
